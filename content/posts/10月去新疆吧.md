2023 年10月因为国庆和中秋重合，所以有8天假期，我们一行是10月1号出发到10月7号，总共7天。10月真的是十分适合去新疆。总体路线是 乌鲁木齐 -> 赛里木湖 -> 五彩滩 -> 禾木 -> 喀纳斯。

---

<!--more-->

<br/>



:partly_sunny: ​近期天气：

10月份 平均10℃，其中赛里木的风是真的大，帽子都能吹掉。建议还是冲锋衣（PS：为了新疆之旅专门买的:dromedary_camel:骆驼冲锋衣，很明显买对了）

<br/>

:vertical_traffic_light:到达新疆的方式：

我们是直接坐飞机在乌鲁木齐地窝堡机场集合，分别从北京、西安、重庆出发，第二天才坐车去赛里木，从早上10点开到下午快5点，中间在路上吃了个饭，耽搁了近2个小时。

之后想再去新疆的话，一定得:flight_arrival:飞机直达，可以飞伯乐机场、阿勒泰机场，最好直达。我们是包车全程的，有好处也有坏处吧，坏处当然是路上太远了，一直在坐车:red_car:。

<br/>

:house: 住宿：

新疆的大城市就建议住华住下的连锁，我们第一晚是住精河一般般，让我感觉住的非常好的酒店是喀纳斯，导游把我们安排在了景区内的阅湖服务中心，真的是吹爆的好，不过也挺贵的，1573元/一晚。禾木的小木屋似乎也是1千多一晚。

还有一晚是住在布尔津县城，布尔津是一个纯粹旅游带起来的县城。



<br/>

:yum: 吃的：

新疆的**羊肉串**是真的大，也不贵10元一串。其他吃的干果类特别多，不过这里都是按公斤卖的，也有点点贵吧。买了一公斤的红香妃葡萄干70元，颗粒是真的大。至于其他的饭嘛... 大盘鸡，手抓饭，烤包子啥的，真没有带来什么惊喜，和北京的新疆驻京办的菜一模一样，只能说北京的驻京办的饭菜太正宗了... 哈哈哈 

> 还有就是烤馕 :cookie: YYDS，在新疆，馕是一种信仰，可以一日无菜，但不可一日无馕。

# 行程

北疆路线：

Day 1  乌鲁木齐 -> 赛里木湖 -> 精河

Day2   精河 -> 五彩滩 -> 布尔津县城

Day3   布尔津 -> 禾木

Day4   禾木 ->  喀纳斯 

Day5   喀纳斯 -> 北屯

Day6   北屯 -> 乌鲁木齐



## 赛里木湖 -- 大西洋的最后一滴眼泪 

真的... 引用撒贝宁的一句话，赛里木湖都没来过，白活了。

第一天刚到乌鲁木齐的时候，感觉这个城市还是比较落后的，可能是自己一直都在大城市，但是到了赛里木湖景区，才感觉到5A景区的实力，赛里木湖在一个从来没听过的地方 -- 博尔塔拉州，紧靠伊利，距离乌鲁木齐 600 公里，

<img src="https://img1.kiosk007.top/static/images/blog/xinjiang06.jpeg" alt="vm1" style="zoom: 33%;clear:both;display:block;margin:auto;" />

赛里木湖是新疆海拔最高的高山湖泊，也是大西洋暖湿气流最后眷顾的地方，因此有“大西洋的最后一滴眼泪”的说法。
