# 数据结构

## Redis 主要数据结构

Redis 提供了多种灵活且高效的数据结构，它们是 Redis 强大功能的基石。

#### 1. String (字符串)

* **特点：** 最基本的数据类型。可以存储文本、整数、浮点数或二进制数据。最大可存 512MB。
* **用途：** 缓存键值对、计数器、分布式锁等。
* **操作：** `SET`, `GET`, `INCR`, `DECR`, `APPEND` 等。

#### 2. List (列表)

* **特点：** 有序的字符串列表，可以在头部或尾部快速插入/删除元素。元素可重复。
* **用途：** 消息队列、日志流、最新事件列表。
* **操作：** `LPUSH`, `RPUSH`, `LPOP`, `RPOP`, `LRANGE`, `LLEN` 等。

#### 3. Hash (哈希)

* **特点：** 键值对的集合，类似于编程语言中的字典或对象。适合存储结构化数据。
* **用途：** 存储用户对象、商品信息等。
* **操作：** `HSET`, `HGET`, `HGETALL`, `HDEL`, `HINCRBY` 等。

#### 4. Set (集合)

* **特点：** 无序的字符串集合，元素唯一。
* **用途：** 标签、社交关系（共同关注）、去重、抽奖。
* **操作：** `SADD`, `SMEMBERS`, `SISMEMBER`, `SREM`, `SINTER`, `SUNION` 等。

#### 5. Sorted Set (有序集合 / ZSet)

* **特点：** 集合的扩展，每个成员都关联一个分数（score），成员唯一但分数可重复。通过分数进行排序。
* **用途：** 排行榜、带权重的任务队列。
* **操作：** `ZADD`, `ZRANGE`, `ZREVRANGE`, `ZSCORE`, `ZINCRBY`, `ZREM` 等。

---

除了以上五种基本数据结构，Redis 还提供了一些高级抽象或特殊用途的模块/结构：

#### 6. HyperLogLog (HLL)

* **特点：** 用于估算海量数据集中不重复元素的数量，内存占用极小。
* **用途：** 统计独立访客 (UV)、独立 IP 数量等。
* **操作：** `PFADD`, `PFCOUNT`, `PFMERGE`。

#### 7. Bitmap (位图)

* **特点：** 字符串类型的一个特殊应用，将字符串看作位数组，按位进行操作。
* **用途：** 用户签到、活跃用户统计。
* **操作：** `SETBIT`, `GETBIT`, `BITCOUNT`, `BITOP`。

#### 8. Streams (流)

* **特点：** Redis 5.0 引入，用于实现高性能、可持久化、多消费者组的消息队列。
* **用途：** 消息队列、日志收集、事件流处理。
* **操作：** `XADD`, `XREAD`, `XGROUP`, `XACK` 等。

#### 9. Geospatial (地理空间)

* **特点：** 基于 ZSet 实现，用于存储地理坐标（经度、纬度），并支持范围查询。
* **用途：** 附近的人、LBS 应用。
* **操作：** `GEOADD`, `GEOPOS`, `GEODIST`, `GEORADIUS` 等。

## Zset (Sorted Set) 使用了什么数据结构？

Redis 的 ZSet（有序集合）底层使用了两种数据结构来协同工作，以实现其高效的存储和操作：

1.  **SkipList (跳跃表)**
    * **作用：** 用于维护有序集合中成员及其分数（score）的排序，并支持快速的插入、删除和查找操作（包括范围查询）。跳跃表是一种概率性数据结构，它通过在多个层级上维护有序链表，使得大部分操作的平均时间复杂度达到 $O(\log N)$。
    * **特点：** 允许在查找过程中跳过部分节点，从而提高查找效率。

2.  **HashTable (哈希表)**
    * **作用：** 用于存储成员（member）到分数（score）以及成员到跳跃表中节点的映射。它提供了 $O(1)$ 的平均时间复杂度来根据成员快速查找其分数或在跳跃表中的位置。
    * **特点：** 确保了对单个成员进行分数查询或更新操作的高效率。

**总结：**

ZSet 通过结合 **SkipList（用于排序和范围查找）** 和 **HashTable（用于快速成员查找）** 这两种数据结构，实现了高效且灵活的有序集合功能。
